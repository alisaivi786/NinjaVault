# NinjaVault.Cdn 100.43.0

Date: 2026-11-05
Type: Minor

## Changes
- `TenantId` is now a `string` instead of a `long`: `CdnUploadRequest.TenantId`, `CdnFileListQuery.TenantId`
  (`string?`), `CdnFileObject.TenantId` and `CdnAccessContext.AllowedTenantIds` (`IReadOnlyList<string>`).
- Responses accept the tenant id as a JSON string or number; a number is kept as its text (`42` -> `"42"`).
- `UploadAsync` rejects a blank `TenantId` before sending, and trims surrounding whitespace.
- README examples use GUID tenant ids.

## Why
- The NinjaVault CDN server switched tenant ids from numeric ids to GUIDs. A `long` cannot hold a GUID, so the
  client could neither upload for a GUID tenant nor read file metadata or `/api/v1/me` for one.

## Breaking Changes
- Code that passes or reads `TenantId` as a `long` no longer compiles. Pass the tenant id as a string, for example
  `new CdnUploadRequest("documents", tenantId.ToString(), stream, "a.pdf")`.
