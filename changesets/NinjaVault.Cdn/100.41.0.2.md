# NinjaVault.Cdn 100.41.0.2

Date: 2026-09-28
Type: Patch

## Changes
- Depends on `NinjaVault.Http` 100.41.0.2, so `DownloadAsync` streams files without the logging handler
  buffering them in memory first.
- Rewritten package README: quick start, full configuration reference, public vs presigned URL guide,
  every operation, error-code table, logging, unit testing, and troubleshooting.

## Why
- Large CDN downloads were buffered in memory by the logging handler when `CaptureResponseBody` was enabled.

## Breaking Changes
- None.
