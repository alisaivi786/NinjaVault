# NinjaVault.Cdn 100.42.1

Date: 2026-09-29
Type: Patch

## Changes
- `CdnUploadResult.ViewUrl` and `CdnFileObject.ViewUrl`: the browser-friendly view URL the server returns, now exposed.
- `BuildPublicUrl` accepts a `PublicBaseUrl` with or without a trailing `/public` (the server's own setting ends in
  `/public`), so copying it no longer produces `/public/public/` URLs.
- README: new "NinjaVault SDKs" section (Python and Node.js packages), section names aligned across the three SDKs.

## Why
- One version number for every NinjaVault SDK: `NinjaVault.Cdn` (NuGet), `ninjavault-cdn` (PyPI) and
  `@ninjavault/cdn` (npm) are all 100.42.1, with the same feature set. npm only allows three-part versions, so the
  shared scheme is `MAJOR.MINOR.PATCH`; 100.42.1 sorts after 100.42.0.1 on NuGet.
- Closes the two gaps found while building the Python and Node.js SDKs against the live server.

## Breaking Changes
- None. `ViewUrl` is an optional init property, so existing constructor calls still compile.
