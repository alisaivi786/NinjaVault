# NinjaVault.Http 100.42.0.1

Date: 2026-09-28
Type: Minor

## Changes
- New `IHttpClientBuilder.AddNinjaVaultHttpLogging(serviceName)`: attaches request/response logging and
  `X-Correlation-Id` propagation to any client registered elsewhere (`AddHttpClient`, an SDK, or
  `AddNinjaVaultCdn`). Registers the shared infrastructure with default options if `AddNinjaVaultHttp` has not
  been called. `AddNinjaVaultHttpClient<TClient, TImplementation>` now uses it internally.
- README: new "Add logging to a client registered elsewhere" section.

## Why
- `NinjaVault.Cdn` is now standalone, so logging is attached per client instead of being built in.

## Breaking Changes
- None.
