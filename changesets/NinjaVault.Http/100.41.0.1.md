# NinjaVault.Http 100.41.0.1

Date: 2026-09-28
Type: Major

## Changes
- First public release on nuget.org.
- `AddNinjaVaultHttpClient<TClient, TImplementation>(serviceName, configure)` registers a typed `HttpClient`
  with `ExternalApiLoggingHandler`: method, URL, headers (sensitive values redacted), truncated bodies,
  status code and elapsed time for every outbound call.
- Binary and multipart bodies (`multipart/*`, `image/*`, `audio/*`, `video/*`, `application/octet-stream`,
  `application/pdf`, `application/zip`) are recorded as a small JSON placeholder instead of decoded text.
- Pluggable `IExternalApiCallLogSink`; a structured-logging sink is registered by default.
- `AsyncLocal`-backed `ICorrelationContextAccessor` stamps `X-Correlation-Id` on every outbound request.
- New `AddNinjaVaultHttp()` overload with no `IConfiguration`, for code-only setups.
- Targets `net8.0`, `net9.0` and `net10.0`.

## Why
- Publish the HTTP logging/correlation layer publicly so `NinjaVault.Cdn` (and any other client) can depend on it from nuget.org.

## Breaking Changes
- None (first public release). Configuration section is `NinjaVault:ExternalApiLogging`.
